# ws_offboard_control

Multi-drone PX4 offboard control with ROS 2 (Humble) — one ROS node flies N
drones simultaneously (single-process, multi-threaded executor), validated in
Gazebo SITL and on real hardware (Holybro S500 + Raspberry Pi companion).

## Layout

| path | contents |
|------|----------|
| `src/multi_sim/` | the ROS 2 package with all nodes |
| `simulation/` | SITL demo + visualization (launch scripts, custom Gazebo city world, RViz 3-D path plot) |
| `hardware_experiment/` | files for real-drone flight tests (S500 + Pi) |
| `src/px4_msgs/`, `src/px4_ros_com/` | PX4 ROS 2 message/bridge dependencies |

## Nodes (`multi_sim`)

| node | purpose |
|------|---------|
| `mission_setpoints` | multi-drone mission FSM (arm → ascend → cruise to targets → land) |
| `arm_test` | force-arm test (bypasses preflight — indoor/no-GPS only, **props off**) |
| `arm_safe` | normal arm with full preflight checks, hold, disarm |
| `hover_test` | offboard hover: arm → climb to `alt` → hold → auto-land (outdoor/GPS) |

## Build

```bash
colcon build            # from this workspace root
source install/local_setup.bash
```

`build/`, `install/`, and `log/` are generated by colcon and are git-ignored.

## Simulation demo

```bash
./simulation/record_demo.sh     # Gazebo city world + 3 drones
./simulation/run_rviz.sh        # RViz 3-D trajectory plot (separate terminal)
```

## Hardware

See notes in `hardware_experiment/`. The companion computer runs the
micro-XRCE-DDS agent over serial to the PX4 flight controller (TELEM2), then the
same `multi_sim` nodes.
